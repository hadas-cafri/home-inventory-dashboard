# 🏠 דאשבורד מלאי ולוגיסטיקה ביתי

דאשבורד לניהול מלאי הבית: מה יש, מה חסר, מה פג תוקף, רשימת קניות לפי חנות ומעקב משלוחים.
הפרויקט עובד עם נתוני דמה (Mock Data).

## הרצה
פותחים את `index.html` בדפדפן, לא צריך התקנה.

## מה יש בדאשבורד
- מדדים: פריטים חסרים, פגי תוקף, משלוחים בדרך, עלות קניות משוערת
- טבלת מלאי עם חיפוש, סינון ועדכון כמויות
- רשימת קניות אוטומטית מקובצת לפי חנות, עם יצירת הזמנה
- מעקב משלוחים, וקבלת משלוח שמעדכנת את המלאי
- גרפים לפי קטגוריה ולפי מצב המלאי
